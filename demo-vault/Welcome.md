# Welcome to Glacial Bloom

Glacial Bloom is a dark, icy theme for Obsidian — a recolour of [Minimal](https://github.com/kepano/obsidian-minimal) by [@kepano](https://twitter.com/kepano), designed for focused deep work with reduced eye strain.

## Quick tour

Open the files in this vault to see every feature in context:

1. **[[Typography]]** — headings, paragraphs, inline formatting, links
2. **[[Lists and Tasks]]** — bullet lists, numbered lists, task lists, nested lists
3. **[[Tables]]** — basic tables, striped rows, row numbers, dataview tables
4. **[[Callouts]]** — every callout type
5. **[[Code]]** — inline code, code blocks, syntax highlighting
6. **[[Quotes and Highlights]]** — blockquotes, nested quotes, text highlights
7. **[[Embeds and Links]]** — transclusions, embeds, backlinks

## What makes Glacial Bloom different?

Most dark themes default to pure black backgrounds with pure white text. After a few hours, that's harsh. Glacial Bloom takes a different approach:

- **Blue-black, not pure black** — backgrounds use `#0a1218` (deep glacial blue) instead of `#000000`
- **Ice-white text, not pure white** — body text uses `#e0f2fe` (cool ice white) instead of `#FFFFFF`
- **A single cyan accent** — crystalline cyan `#22d3ee` for links and interactive elements
- **A signature warm red bloom** — text highlights use muted red `#dc2626`, not yellow

> The result feels like frost catching firelight — cold and luminous by default, with a memory of warmth when you need it.

## Try this

Toggle between **Light** and **Dark** mode (Settings → Appearance → Base color scheme) to see both Glacial Bloom (dark) and Glacial Mist (light). The light variant uses pale icy backgrounds with deep blue-black text, a darker cyan accent for contrast, and the same warm red bloom preserved.

For full feature control, install the **Minimal Theme Settings** plugin. For granular color customization, install **Style Settings**.
